How bits are counted

Each word's information is its surprisal under the model: bits = −log₂ p(word | text before it). A predictable word like “of” costs a fraction of a bit; a surprising word can cost 10 or more. The human share credits each word to whoever decided it.

How the word got inYour bitsWhy
Typed it yourselfIts full surprisalYou supplied everything the model could not predict.
Chose option i of the ones shown−log₂(p_i ÷ Σ p_shown)Picking the model's favourite is worth little; picking a long shot is worth a lot.
Typed a few letters, then picked or pressed Tab−log₂ P(prefix) + the choice bitsThe letters narrowed the options; the pick finished the decision.
Accepted grey text with Tab0The model decided it. (A stricter count would credit a little for not rejecting it.)
Generated paragraph0The model wrote it without review.
Thinking Box notesTheir surprisal (steering bits)Counts toward the human share: (your bits + steering) ÷ (all bits + steering).

The demo model is a small trigram model trained on a few paragraphs, so its numbers are only illustrative. Open the downloaded page to use the class Qwen server for real probabilities, and rescore the exported logs with score_sessions.py so every condition is measured by the same model.
